# would be a released migration that nothing protects, and the protection would decay unnoticed.

# fixed in place, and it is still judged by the review rules of scripts/lint-migrations.mjs):
#     node scripts/lint-migrations.mjs --hash <folder>
# and paste the line it prints below. A folder that is not listed must have a timestamp LATER
